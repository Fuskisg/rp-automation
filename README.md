# RP Automation

Самостоятельная модульная панель автоматизации для Windows. Код, архитектура и интерфейс написаны отдельно. В `assets/templates` лежат шаблоны картинок из предыдущего локального проекта: они используются только для проверки распознавания на твоём экране.

## Возможности

- Anti‑AFK с тремя рисунками движения;
- редактор сценариев `tap`, `hold`, `wait` с повторами;
- единый слой ввода и остановка активного модуля;
- безопасный режим: по умолчанию нажатия только журналируются;
- журнал событий в интерфейсе и `logs/automation.log`;
- распознавание шаблонов и цветных индикаторов через `mss` и OpenCV в папке `vision`.
- страница «Мини‑игры» с понятными категориями, выбором шаблона и проверкой текущего экрана;
- 95 готовых PNG/JPG-шаблонов для категорий `cook`, `cow`, `gym`, `heal`, `relogin`, `shveika`, `spin`, `stroyka`, `tokar`.

## Запуск

Установи Python 3.10 или 3.11 на Windows 10/11 и дважды запусти `run.bat`. Либо вручную:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python main.py
```

Сначала оставь включённым безопасный режим. Открой вкладку «Распознавание», выбери категорию и картинку и нажми «Проверить экран». Приложение покажет точность совпадения и координаты, но само по себе не кликает по результату. Шаблоны зависят от разрешения, масштаба интерфейса и настроек игры.

## Что находится в проекте

- `main.py` — окно приложения;
- `core/` — настройки, ввод и журнал;
- `modules/` — Anti-AFK и редактор сценариев;
- `vision/` — захват экрана и OpenCV-распознавание;
- `assets/templates/` — изображения для проверки.

Категории в интерфейсе: «Готовка», «Ферма: коровы», «Качалка», «Медицина», «Переподключение», «Швейка», «Казино», «Стройка» и «Токарь». В каждой категории можно выбрать отдельный шаблон.

`vision/legacy_detector.py` — отдельный совместимый слой, перенесённый из предыдущего проекта по запросу владельца. Новое окно приложения не зависит от его старого интерфейса.
