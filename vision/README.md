# Распознавание мини-игр

Папка содержит независимый слой компьютерного зрения для нового проекта:

- `ScreenGrabber` получает кадры через `mss`;
- `TemplateMatcher` ищет подсказки по шаблонам через `cv2.matchTemplate`;
- `ColorSignalDetector` находит цветные индикаторы через HSV-маску и контуры;
- `Match` возвращает координаты и уверенность совпадения;
- подавление пересечений не даёт одному шаблону породить десятки одинаковых срабатываний.
- `legacy_detector.py` содержит перенесённый рабочий слой из предыдущего проекта: шаблонные подсказки, HSV-контуры и проверку изображения на экране.

Алгоритмы подходят для разных мини-игр, но шаблоны и координаты должны быть сняты с конкретного разрешения и интерфейса пользователя. Исходные игровые картинки из другого проекта сюда не копируются.

`legacy_detector.py` помечен отдельно, потому что это кодовая база старого проекта, перенесённая по запросу владельца текущего проекта.
